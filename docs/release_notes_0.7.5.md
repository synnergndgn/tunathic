# Tunathic 0.7.5+15

- New launcher icon: the analog tuner movement, matching the Play listing icon.
  The tuning fork it replaces is retired from the app icon.
- Added a themed-icon (monochrome) variant, so the icon follows the system
  wallpaper theme on Android 13 and later instead of falling back to a tinted
  copy of the colour icon.
- Enabled predictive back, so the Android 13+ back gesture previews where it is
  taking you.
