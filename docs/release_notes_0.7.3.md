# Tunathic 0.7.3+13

- Improved tuner screen performance, especially during silence.
- Simplified the main tuner interface.
- Moved tuning systems and A4 reference settings to a dedicated settings page.
- Removed the unnecessary stop-tuning control and no-signal message.
- Refined the automatic/manual tuning flow and target-string presentation.
- Kept the tuner frame visually stable while pitch indicators update.
- Prevented tempo, state, navigation, and tuner updates from stopping the metronome.
- Added automatic metronome recovery after an unexpected native audio interruption.
