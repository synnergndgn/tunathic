# Closed Test Screenshot Plan

Use a release or profile build on a representative phone. Use realistic,
non-sensitive state, a clean status bar, consistent theme, and no debug banner
or diagnostics. Capture English first, then matching Turkish variants for the
localized listing.

| Order | Screen | Suggested demo state | What it proves |
| ---: | --- | --- | --- |
| 1 | Home / Guitar toolkit | All Ready and Coming Soon labels visible; no transient dialogs | Product scope and navigation |
| 2 | Guitar Tuner | Permission already granted; stable A string near 440 Hz; do not imply impossible precision | Primary utility and local pitch feedback |
| 3 | Metronome | Running at 120 BPM, 4/4, accent on | Tempo controls and beat clarity |
| 4 | Chord Library | Familiar chord with diagram plus one alternative | Practical voicing content |
| 5 | Scale Library | A Minor or E Minor with formula and notes | Offline scale reference |
| 6 | Interactive Fretboard | Selected chord or scale, readable note/degree display | Interactive theory projection |
| 7 | Circle of Fifths | A selected major/minor key with relationships visible | Harmony reference and navigation |

## Capture matrix

- [ ] Phone portrait, 9:16 recommended, at a modern high resolution.
- [ ] English complete set.
- [ ] Turkish complete set if Turkish listing/assets are published.
- [ ] Tablet set (at least four useful screens) if the tablet listing slot is
      used; prefer native tablet captures over framed phone images.
- [ ] Light/dark choice is consistent across a set unless theme support is the
      explicit story.
- [ ] No user names, messages, account data, microphone notification history,
      device identifiers, or unrelated notifications.
- [ ] No Coming Soon tool is presented as an available feature.
- [ ] No claims of zero latency, perfect/studio accuracy, or certification.
- [ ] Verify screenshots match the exact closed-test build.
